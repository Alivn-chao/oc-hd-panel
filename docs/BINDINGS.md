# 本地 OCHD 地址绑定：保留用户 alpha4 的1080p与修复

基准是用户提供的 `oc-hd-panel-0.3.0-alpha4.jar`，SHA256为 `6ff5a5bd5a8d7caf0d544d29fb9a8140d3c241a165cea3efa9bb01cfb8578b69`。原公开仓库只有alpha3，没有这份alpha4源码，因此根据字节码差异恢复了画布、朝向、边框、纹理和刷新修复。最终发行物再对原alpha4作受限类覆盖，仅替换绑定所需的类；其余类和资源逐文件保持原字节，清单见 `alpha4-preservation.json`。普通Gradle staging jar不是经过此保留检查的最终发行物。

## 安装与使用

1. 退出控制服务，客户端和服务器都把旧OCHD jar替换为 `oc-hd-panel-0.3.1-alpha4-bindings.jar`，不要在同一端保留两份；原包另存。重启以加载模组。
2. OC里运行测试包 `oc/install_bindings.lua`，或手动复制同目录三个Lua文件到 `/home`。安装器验证语法、临时文件flush/回读、备份及失败回滚，不改配置、配方或运行记录，不启动机器。
3. V2已安装时运行 `lua /home/bec_v2_setup_hd.lua`，右键OCHD → 顶部“设置” → “设备地址绑定”。此程序只配置，不启动生产。
4. 文本框支持Ctrl+V粘贴、Ctrl+A全选、退格、方向键和Tab；上一页/下一页查看字段。方向：0下、1上、2北、3南、4西、5东。
5. 保存后等待OC成功回执，写入 `/home/bec_v2/config.dat`，旧配置保留 `.hd.bak.<请求编号>`。按OC键盘Q退出配置服务，再启动原V2入口。

支持1–16个节点位置，空位编号保留，节点与暂停红石必须一起填写；已有多个设备组时逐组编辑。组内公共设备、最多16台纠缠器、至少5个可选高速口、两种蜂群模式及方向可编辑。初次空配置默认一个公共组，新增设备组仍用V2 setup向导。

有未完成生产/换蜂/cohort记录、未确认搬液或申请、设备仍在运行、组件类型不符或重复地址时拒绝保存。页面携带配置指纹，其他玩家或程序改过配置后，旧页面不能直接覆盖。保存不执行Lua字符串，不写机器输出，也不自动启动控制器。

V1使用 `lua /home/bec_hd.lua monitor` 后，同一入口可改高清监控的节点/约束场两项连接，保存到 `/home/bec_hd.config`。这是高清监控地址，不重写固定地址V1生产控制器；运行中的控制器须先暂停退出。
