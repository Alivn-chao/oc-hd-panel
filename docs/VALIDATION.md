# 验证记录（2026-10-13，0.3.0-alpha3）

目标：GTNH 2.9.0 beta3 中 OC 1.12.61-GTNH；Forge 10.13.4.1614、lwjgl3ify 3.0.31。

已完成：

- RFG 2.0.5 编译、JUnit 测试和 reobfJar；发布重混淆安装 jar，项目类为 Java 8 字节码，未打入 OC/Minecraft 类。
- 13 项 Java 测试通过：原数据边界、有限数值、UTF-8/Lua 数组、库存上限、输入/选区、请求编号/超时与滚动；新增页面/控件布局边界、ID 唯一性、默认禁用、控件命中和操作值；全部 1×1 至 8×6 组合的纹理切片面积、UV 范围与 16:9 比例；矩形缺口/多绑定者/尺寸拒绝条件；紧凑窗口比例与可选放大。
- 三份 OC Lua 脚本语法检查通过。通用演示模拟验证页面定义、开关目标事件、重置计数、回执和解除绑定；不访问机器。
- BEC monitor/run/resume 三种模拟流程通过原按键路由、恢复入口、缓存目标读取、权限模式和退出清理检查。
- 8 种 BEC 配置事务模拟通过：保存/备份、只读拒绝、flush/读回失败、重命名失败/异常回滚、损坏配置拒绝、缺失配置且存在备份时拒绝启动。保留单项 0 停补设置。
- 欢迎页与通用演示预览由实际 AppPainter 生成并进行图片检查；保留的 BEC 图片为实际 DashboardPainter/InteractionPainter 的演示数据，全部不是游戏截图。

尚未完成：真实游戏内屏幕墙发现/OC 组件可见性、连接一个或多个电脑、各朝向无缝渲染、跨区块拼接/拆除/卸载/重连、多人权限、键鼠与真实回执路由、机器操作、真实 OC 磁盘写入以及 FPS/MSPT。纯几何测试不能证明世界拼接与 OC 网络行为正确。

用户提供的旧 alpha2 截图显示 GUI 已能打开，但尚未连线；不能据此认定 alpha3 的新增功能已在游戏中验证。本次未启动游戏、替换实例 mods 或修改游戏 OC 文件。

建议实测：同朝向搭 5×3 矩形并等待 1 秒 → 连接一台 OC 电脑核对只出现一个 hd_panel → 运行 automation_demo.lua → 世界画面连续且四种朝向正确 → 右键任意格打开约 45% 宽的窗口 → 开关、回执、F6 → 拆除角块并重新补全 → 重连与区块卸载。多墙测试独立地址与最多 4 面纹理缓存。最后在同地点/同视角记录无面板、演示面板、只读机器面板各 60 秒的 FPS/帧时间与服务器 MSPT。

本版是预发行 Alpha；编译和模拟测试不能替代上述实测。
