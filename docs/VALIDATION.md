# 验证记录（2026-10-13）

适配目标：用户 GTNH 2.9.0 beta3 客户端中的 OC 1.12.61-GTNH；Forge 10.13.4.1614，lwjgl3ify 3.0.31。

已完成：

- RFG 2.0.5 编译、测试与 reobfJar 成功；发布的是重混淆安装 jar，非 dev jar。
- 7 项 Java 测试通过：数据字段边界、非有限数值、UTF-8/Lua 数组与 32 行上限、按钮区域、无效数据回退、数值与选区编辑、请求回执编号匹配/超时、滚动边界与最后一行可达。
- 两份 Lua 脚本通过语法检查；monitor/run/resume 三种模拟流程通过权限模式、按键路由、正确恢复入口、缓存目标读取、退出恢复全局函数和解除绑定检查。
- 8 种 Lua 配置事务模拟通过：保存/备份、只读拒绝、flush 失败、读回失败、重命名失败/异常回滚、原配置损坏拒绝、配置缺失且存在备份时拒绝启动。测试模拟 OC close() 成功不返回值，并核对保留单项 0 停补设置。
- 1280×720 总览、库存、事件、设置、离线、输入框与确认弹窗图片由实际 DashboardPainter / InteractionPainter 生成；库存与表单画面经过视觉检查。图片为演示数据，不是游戏截图。
- 纯 Java2D 绘制测得 30 次热运行平均约 6.6ms，运行于后台绘制实现对应的绘图代码；不包括 Minecraft 帧时间、GPU 纹理上传或服务器开销。
- jar 内容检查：所有项目类为 Java 8 字节码；未打入 OC 或 Minecraft 类；包含语言文件、方块纹理与模组信息。

未完成：真实 GTNH 启动、实际 OC 网络连接、世界方块显示/朝向、游戏中鼠标/键盘/剪贴板操作、网络回执实际路由、配置写入真实 OC 磁盘、点击与 BEC 实际交互、区块卸载/重连、多玩家权限以及 FPS/服务器 MSPT 测量。

安装顺序：客户端/服务器安装相同 jar → 显示演示 → 只读 BEC → 实机核对后再使用原控制器的控制入口。现有实例 mods 和游戏 OC 文件未被自动修改。

公开版将专用组件地址改为 bec_hd.config 配置；Lua 路由与配置事务模拟在公开版本上重新执行。尚未完成游戏实测。
