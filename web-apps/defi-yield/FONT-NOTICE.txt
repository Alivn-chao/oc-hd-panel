Neon Orbit Bold is a local static 700-weight instance derived from Orbitron. The modified font family/PostScript names were changed to Neon Orbit / NeonOrbit-Bold. Original copyright and SIL OFL are retained in the embedded font and accompanying OFL.txt. Source: https://github.com/google/fonts/tree/main/ofl/orbitron ; generated with fontTools varLib.instancer at wght=700. CSS embeds the complete static TTF as a data URL; no external font requests.
