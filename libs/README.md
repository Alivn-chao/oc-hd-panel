构建前准备官方 GTNH 2.9.0 正式版的以下编译依赖；它们不随 OCHD 发行包分发：

- `OpenComputers-1.12.68-GTNH.jar`（GTNH OpenComputers 官方发布）
- `AE2-rv3-beta-1095-GTNH-api.jar`（将官方 `appliedenergistics2-rv3-beta-1095-GTNH-api.jar` 保存为此名称）
- `CoFHCore.jar`：整合包中的 CoFH Core 3.1.4-329
- `IC2.jar`：整合包中的 IndustrialCraft 2 2.2.828 experimental

版本来源、下载地址和 SHA-256 见 `docs/GTNH_2.9.0.md`。构建工具要求 Java 25，模组源码仍以 Java 21 工具链编译为 Java 8 字节码。
